# emoselfie UI Kit

업로드된 로고의 시각 언어를 참고해 만든, 빌드 과정 없이 바로 열어볼 수 있는 웹 UI 컴포넌트 예시입니다.

포함:
- 브랜드 Hero
- 감정 미션 카드
- 감정 칩
- AI 판정/점수 카드
- 플레이어 리더보드
- 버튼/토스트
- 모바일 홈 카드 예시

사용:
1. `index.html`을 브라우저에서 열기
2. `emoselfie-components.css`에서 컬러/라운드/외곽선 토큰 수정
3. 필요한 컴포넌트 마크업만 프로젝트로 복사

스타일 핵심:
- 두꺼운 검정 외곽선
- 핑크 / 옐로 포인트
- 말풍선/스티커 느낌
- 둥근 카드와 눌리는 버튼
- 장난스러운 AI 판정 카피
